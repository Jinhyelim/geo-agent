# AI 활용 개발 기록

AI(Claude)와 함께 개발하면서 **AI가 제안한 코드에서 발견한 문제와 수정 과정**을 기록한다.
포트폴리오의 "AI 활용 개발 방식" 페이지 재료로 쓴다.

| 날짜 | AI가 제안한 것 | 발견한 문제 | 어떻게 발견했나 | 수정 |
|---|---|---|---|---|
| 2026-10-13 | 기존 가상환경(.venv) 그대로 사용 | 폴더 이동 후 pip.exe가 옛 경로를 참조해 실행 실패 | `pip --version` 실행 결과 확인 | 현재 위치에서 venv 재생성 |
| 2026-10-13 | DB 이미지로 `postgis/postgis:16-3.4` + pgvector 설치 | 베이스 이미지가 지원 종료된 Debian bullseye라 PostgreSQL apt 저장소 404로 빌드 실패 | `docker compose up --build` 오류 로그(`bullseye-pgdg Release 404`) | 최신 Debian 기반 `pgvector/pgvector:pg16`에 PostGIS를 설치하는 방향으로 뒤집음 |
| 2026-10-14 | 지오코딩: 카카오 키워드 검색 → 주소 검색 순서로 고정 | "세종대로 172"(주소)가 "광화문역 5호선"으로, "사직동"(행정동)이 "경희궁"으로 잡힘 | 장소 5개로 도구를 단독 실행해 결과 확인 | 질문 형태별로 순서 분기: 행정동 이름은 DB 중심좌표, 주소는 주소 검색 먼저 |
| 2026-10-14 | 주소 판별 정규식 `(로\|길)\s*\d` | "종로3가역"의 '종로3'이 주소로 오판되어 엉뚱한 주소 반환 | 위와 같은 단독 실행에서 재확인 | 도로명 뒤 띄어쓰기를 필수로 `(로\|길)\s+\d` |
